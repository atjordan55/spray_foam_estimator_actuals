Currently to create a material Jobber line item:
*Line Item name - Area Name ((Foam Type) (Foam Thickness)) 
*Line Item description - Dictated by the Jobber Descriptions outlined in the Admin Console (Jobber Quote — Material Line Item Descriptions) (Based off of Area Type and Foam Type ie. Exterior Walls / Closed Cell description block)

*Line Item Unit Price - Equal to ($/Sq Ft)

*Line Item description - Dictated by the Jobber Descriptions outlined in the Admin Console (Jobber Quote — Labor Line Item Description)

*Line Item Unit Price - All costs in the estimator estimate outside of the cost for materials and material markup
